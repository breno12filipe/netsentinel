NetSentinel

Sistema de Monitoramento Integrado de Saúde de Serviços e Infraestrutura de Rede.

Varreduras concorrentes de alta performance cobrindo o Modelo OSI nas Camadas 3, 4 e 7 com arquitetura bottom-up em Java Spring Boot.

Java 17+ Spring Boot ScheduledExecutorService Docker & Compose OpenAPI / Swagger

Arquitetura Multi-Camadas (Modelo OSI)

O NetSentinel realiza diagnósticos ativos de conectividade em três camadas fundamentais da rede:

Camada 3 (Rede) - PING

ICMP Echo Request/Reply. Avalia alcance básico de IP e latência (RTT) sem depender de portas abertas.

Camada 4 (Transporte) - TCP

Socket Handshake (3-Way). Valida se daemons/serviços (Postgres, Redis) estão escutando em portas específicas.

Camada 7 (Aplicação) - HTTP

HttpClient com verbos otimizados (HEAD). Valida a integridade lógica e os Status Codes esperados das APIs.

Motor Concorrente & Threads

Gerenciamento de tempo real projetado para baixa latência e concorrência com ScheduledExecutorService e ConcurrentHashMap:

// Agendamento thread-safe atômico com delay fixo para evitar acúmulo de pacotes ScheduledFuture<?> future = executorService.scheduleWithFixedDelay( () -> performCheck(target), 0, target.getIntervalSeconds(), TimeUnit.SECONDS );

Garante que o re-agendamento de alvos alterados via API REST ocorra sem interromper ou travar a execução das outras checagens ativas.

Infraestrutura Conteinerizada

Ambiente isolado configurado via Docker e Docker Compose com suporte a DNS interno entre containers:

NetSentinel App

Container Java (Eclipse Temurin JRE Alpine) compilado via Multi-stage build na porta 8080.

Test Targets (L4 & L7)

Nginx (HTTP:80), PostgreSQL (TCP:5432) e Redis (TCP:6379) integrados para testes imediatos.

Docker Network

Rede bridge unificada garantindo resolução de nomes direta (ex: host: "test-postgres").

Visão de Futuro & Próximos Passos

2. Prometheus & Grafana

Expor /metrics via Micrometer para montagem de dashboards visuais de latência e disponibilidade.

3. Webhooks & Alertas

Notificações instantâneas via Discord/Slack quando um alvo alterar do status UP para DOWN.
